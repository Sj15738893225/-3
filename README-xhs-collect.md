# 小红书采集脚本说明

## 怎么运行
1. 双击 run_xhs_collect.bat，或运行 python collect_xhs.py。
2. 首次运行如果未登录小红书，Chrome 会打开登录二维码，用小红书 App 扫码一次。
3. 脚本自动搜索 5 个关键词，按“最热”排序，逐篇打开前 20 条笔记并读取点赞、收藏、评论数和评论原文。
4. 完成后自动更新 ai-digital-product-market-signals.html，并保存原始数据到 xhs_data/raw_results.json（该文件夹不会推送到 GitHub）。

## 关键词
AI提示词 / AI文案代写 / 小红书代运营 / Prompt模板 / AI工具测评

## 诚实说明
- 小红书没有独立的“按点赞排序”，脚本使用平台公开的“最热”排序，并同时记录每篇实际点赞数。
- 评论为笔记页首屏能加载到的公开评论，每篇最多记录 30 条，不代表全部评论。
- 如果触发平台风控，某篇会标记“未获取”，脚本会继续采集其他笔记。

## 断点续跑
脚本每次完成一个关键词就保存一次；中途中断后重新运行，已完成的词会自动跳过。
